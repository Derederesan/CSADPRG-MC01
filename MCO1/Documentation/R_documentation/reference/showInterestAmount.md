# Show Interest Amount

Prints the user's account details, ie. name, balance, base currency,
interest rate. Afterwards, prompts the user for the total number of
days, using it to evaluate daily interest behavior based on the amount
of days the user has selected. It then prints the details in a formatted
string, displaying the details cleanly.

## Usage

``` r
showInterestAmount(accountName, balance)
```

## Arguments

- accountName:

  The string value that represents the current user's account name from
  main.

- balance:

  A numeric value that represents the user's currently held balance from
  main.
