# Valid Choice I/O For Name

Takes a string, and uses nchar as a way to count the number of
characters present in the stdin, ensures it is within maxLen.

## Usage

``` r
getValidName(promptText, maxLen)
```

## Arguments

- promptText:

  A specified string value that is printed to help guide the user.

- maxLen:

  A defined integer value that determines the maximum size of the
  string.

## Value

A validated string of characters.
